# Shell tooling checks, 2026-11-19

Implementation branch: `test/shell-contracts`, based on `bf07e7b8c4137b08c4d925af8c16389adc44ffae`. This is local native x64 development evidence on Windows 10.0.26300, not minimum-system, ARM64, clean-system or frozen-candidate acceptance. The actual shell versions were cmd on Windows 10.0.26300.9974, Windows PowerShell 5.1.26100.9818 and PowerShell 7.7.0.

The actual CLI now runs through generated cmd and PowerShell command files in a private hidden console/job. Ordinary tests cover 16 cases per shell: bare/short/long help, version, Unicode regex errors, bound empty and leading-dash values, literal percent signs, and validation-only forms of all eight VM query commands. Those query-shaped forms append an invalid ROOT, so complete argument validation rejects them before registry I/O. The ordinary helper creates no globally navigable fixture.

Each case records exact direct-CLI argument arrays and reference streams/status, shell path/version, generated script bytes, raw output bytes/BOM/line endings and immediately captured exit codes. Cmd redirection must equal the CLI bytes. PowerShell object capture, explicit UTF-8 Out-File and `>` are checked separately, including Windows PowerShell's UTF-16LE/BOM redirection, UTF-8/BOM Out-File and PowerShell 7.4+ byte-preserving native stdout. Unicode and error content must survive allowed shell-specific stderr formatting. The caller's console code pages are checked unchanged; `chcp` and encoding changes stay inside the isolated worker. No profile or persistent setting is modified.

The [VM suite](../vm-testing.md) adds a separately guarded shell case with a fresh owned Unicode/space-named key and five data values. It requires all three shells and verifies real 0/1/2 query outcomes, literal backslashes, empty default/name patterns, a leading hyphen, percent/dollar data, a quote represented by the existing regex escape and explicit EXPAND_SZ matching. This case has **not run**. Setup/query token checks, bundle identity and external rollback remain mandatory. Its syntax has been exercised by the ordinary invalid-ROOT preflights; those preflights do not prove its query results.
